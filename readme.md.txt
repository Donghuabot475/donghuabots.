# DonghuaBOT — Donghua with Sinhala Subtitles

A modern, responsive streaming/discovery platform for Chinese animation (Donghua) with Sinhala subtitles.

## Features

- **Responsive Design**: Works on mobile (320px+), tablet, laptop, desktop, and large monitors
- **Dark Cinematic Theme**: Premium streaming-style interface with custom color palette
- **Hero Carousel**: Featured donghua with auto-rotation and navigation
- **Search**: Real-time search by title, alt title, genre, episode, and description
- **Genre Filtering**: Browse donghua by genre with active filtering
- **Watchlist**: Client-side watchlist using localStorage with add/remove functionality
- **Continue Watching**: Saves viewing progress to localStorage
- **Video Player**: Custom HTML5 video player with controls, subtitles selector, and keyboard shortcuts
- **Schedule Page**: Weekly release schedule with day grouping
- **Login/Register Modal**: Frontend demo with clear backend integration points
- **Sinhala Language Support**: Unicode-compatible Sinhala text throughout the UI
- **Smooth Animations**: Scroll reveals, card hover effects, and page transitions
